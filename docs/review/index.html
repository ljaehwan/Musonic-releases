Musonic playback demo

Google Play build 0.4.2 (1050), recorded on Android 16. This recording uses the dedicated review server and original demo music.

  1. Open an album from the library.
  2. Tap Play all to start playback.
  3. Open the player to see elapsed playback time.
  4. Return to the home screen and open Android notifications. The Musonic media control remains active while playback continues.

The recording has no audio track. Playback state and progress are visible in the app and system media control. This is an actual app recording, without simulated UI.
