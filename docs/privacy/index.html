Privacy Policy

1. 적용 범위와 운영자

이 방침은 Android 음악 앱 Musonic에 적용됩니다. 운영자: hwanlog. 개인정보 문의: hwandevlog@gmail.com. Musonic은 사용자가 지정한 Subsonic 또는 OpenSubsonic 호환 서버에 연결하는 클라이언트입니다. 음악이나 서버 계정을 제공하거나 Musonic 계정을 생성하지 않습니다.

2. 기기에 저장하는 정보

연결 이름, 서버 주소, 사용자 이름, 비밀번호 또는 API 키, 인증 방식과 연결 설정을 기기 내부에 저장합니다. 서버 프로필은 Android Keystore 키를 이용한 AES-GCM 암호화로 보호합니다. 최근 재생 정보(곡 식별자·제목·아티스트·앨범·표지 식별자·길이·좋아요 상태)는 서버 프로필별로 최대 5,000곡까지 기기 내부 데이터베이스에 저장합니다. 언어, 테마, 음질, 이퀄라이저와 사용자 프리셋 설정도 기기에 저장합니다.

앨범 표지 캐시는 기기 저장 공간에서 최대 160 MiB를 사용하며 메모리에도 임시 보관됩니다. 표지 캐시에 인증 정보가 포함된 요청 URL은 저장하지 않습니다. 현재 음악 파일을 영구 다운로드하여 오프라인 보관하는 기능은 없으며 재생 중 음악 데이터가 임시 버퍼에 처리됩니다. 앱은 Android 자동 백업을 사용하지 않습니다.

3. 음악 서버에 보내는 정보

로그인, 탐색, 검색, 스트리밍, 앨범 표지와 좋아요 기능을 제공하기 위해 사용자가 선택한 서버로 사용자 이름, 인증 값, 곡·앨범 식별자, 검색어, 좋아요 변경 및 요청한 음질 설정을 전송합니다. 기본 인증은 매 요청의 임의 salt와 비밀번호에서 계산한 Subsonic 토큰을 사용합니다. API 키 인증은 API 키를, 레거시 인증은 비밀번호를 16진수로 인코딩한 값을 보냅니다. 인코딩은 암호화가 아닙니다.

Google Play 배포본은 HTTPS만 허용합니다. GitHub 직접 배포본은 기본적으로 HTTPS를 사용하며 사용자가 경고를 확인하고 HTTP를 허용한 경우 암호화되지 않은 연결도 가능합니다. 서버와 프록시 운영자는 IP 주소, 접속 시각, 인증 또는 요청 정보를 서버 설정에 따라 기록할 수 있습니다. 로그 저장 기간과 이용 방법은 해당 서버 운영자의 방침을 확인하세요. Musonic 개발자는 임의의 사용자 서버와 그 기록을 관리하지 않습니다.

4. 다른 서비스와 시스템 연동

앱에는 광고, 행동 분석, 별도 오류 보고 SDK가 없고 Musonic 개발자에게 재생 기록이나 로그인 정보를 보내는 중앙 수집 서버도 없습니다. Android 미디어 알림, 잠금 화면, 연결된 Android Auto 및 허용된 시스템 미디어 컨트롤러에는 재생 기능에 필요한 곡 정보·앨범 표지·재생 상태가 제공됩니다. 마이크, 연락처, 위치, 사진 접근 권한을 요청하지 않습니다.

GitHub 직접 배포본은 시작 시와 약 24시간 간격의 백그라운드 작업으로 GitHub 릴리스를 확인하며, 사용자가 선택하면 APK와 검증 정보를 다운로드합니다. 이 통신은 GitHub 및 다운로드 서비스에 IP 주소와 일반 HTTP 요청 정보를 전달하며 음악 서버 로그인 정보는 전달하지 않습니다. Play 배포본에는 이 다운로드·설치 기능이 포함되지 않으며 업데이트는 Google Play가 관리합니다. 이 웹페이지를 열면 호스팅 제공자 GitHub Pages가 일반 웹 요청 정보를 처리합니다. GitHub 개인정보처리방침을 참고하세요.

5. 보관과 삭제

앱 설정에서 서버 연결의 ‘기기에서 삭제’를 선택하면 해당 서버의 저장된 프로필과 최근 재생 기록을 제거합니다. 서버 계정, 서버 음악 파일과 서버 로그는 삭제되지 않습니다. 기존 앨범 표지 캐시는 연결 삭제 후에도 남을 수 있으며 Android 설정 → 앱 → Musonic → 저장공간 → 캐시 삭제로 제거할 수 있습니다. 같은 화면의 데이터 삭제 또는 앱 제거로 앱의 로컬 프로필·기록·설정·캐시를 삭제할 수 있습니다. 직접 배포본에서 받은 업데이트 APK는 앱 내부 파일 영역에 저장됩니다. 다음 업데이트 파일 다운로드가 완료되면 이전 파일을 정리하며, Android 설정의 데이터 삭제 또는 앱 제거로 모두 지울 수 있습니다.

서버 계정이나 서버에 저장된 데이터 삭제는 해당 서버 관리자에게 요청하세요. Musonic은 서버 계정을 생성하거나 서버 운영자를 대신해 계정을 삭제하지 않습니다. 개인정보 문의를 보낼 때 비밀번호, API 키 또는 인증 값이 포함된 URL을 보내지 마세요. 문의를 위해 제공한 연락처와 내용은 해당 문의를 처리하는 데 사용합니다. 문의 내역은 문의 처리와 필요한 후속 대응을 위해 보관하며, 처리 목적이 달성되면 삭제합니다. 법령상 보관 의무가 있는 경우 해당 기간 동안만 보관합니다. 문의 내역 삭제와 개인정보 관련 요청은 위 이메일로 보내실 수 있습니다. 이메일 문의는 Gmail을 통해 처리되며, Google의 이메일 서비스 처리에는 Google 개인정보처리방침이 적용됩니다.

6. 변경

처리 방식이 바뀌면 이 페이지의 방침과 시행일을 갱신합니다.

1. Scope and operator

This policy applies to Musonic for Android. Operator: hwanlog. Privacy contact: hwandevlog@gmail.com. Musonic connects to a Subsonic or OpenSubsonic server selected by you. It does not supply music, host your music account, or create a Musonic account.

2. Information on your device

Server labels, addresses, usernames, passwords or API keys and authentication settings are stored in app-private storage. Profiles are encrypted with AES-GCM using an Android Keystore key. Recent-play metadata is stored locally for up to 5,000 unique tracks per profile. Language, appearance, streaming quality, equalizer and saved presets are stored locally. Artwork uses an on-device disk cache limited to 160 MiB and a temporary memory cache; credential-bearing request URLs are not written to the artwork cache. Music is buffered for playback; permanent offline music downloads are not currently offered. Android automatic app backup is disabled.

3. Requests to your music server

To authenticate, browse, search, stream, load artwork and change favorites, the app sends your username, authentication values, media IDs, search terms, favorite changes and quality parameters to your chosen server. Token authentication sends a salted Subsonic password hash; API-key mode sends the key; legacy mode sends a hex-encoded password. Encoding is not encryption.

The Google Play build requires HTTPS. The direct GitHub build uses HTTPS by default and allows unencrypted HTTP only after explicit user opt-in. Server and proxy operators can see your IP address, request timing and request data and may retain logs according to their settings. Contact your server operator about its retention practices. The Musonic developer does not control independently operated music servers.

4. Other services

The app includes no advertising, behavioral analytics or crash-reporting SDK and sends no music credentials or listening history to a central Musonic collection service. Track metadata, artwork and playback state are provided to Android media notifications, lock-screen controls, connected Android Auto and authorized system media controllers. The app does not request microphone, contacts, location or photo permissions.

The direct GitHub build checks GitHub releases at startup and through a roughly daily background job. If you choose to update, it downloads APK and verification data. GitHub and its download services receive your IP address and normal HTTP request information, but not your music-server credentials. These update/download/installer components are excluded from the Google Play build; Google Play manages its updates. Visiting this policy webpage also sends ordinary web request information to GitHub Pages. See the GitHub Privacy Statement.

5. Retention and deletion

Removing a connection in Musonic settings removes its local profile and recent-play history. It does not delete the server account, server music or server logs. Artwork may remain cached; clear it through Android Settings → Apps → Musonic → Storage → Clear cache. Clear app data or uninstall to remove local profiles, history, preferences and cache. Downloaded update APKs in the direct build are stored in app-private files, not the artwork cache. Older update files are removed after a new update download completes; clearing app data or uninstalling removes all of them. Ask the music-server operator to delete server accounts or server-side data. Musonic does not create or delete server accounts. Do not include passwords, API keys or authenticated URLs in support requests. Contact details and messages you voluntarily provide are used to address your inquiry. Support correspondence is retained to resolve your inquiry and necessary follow-up, then deleted once that purpose is fulfilled, except where retention is required by law. You may request deletion or contact us about privacy at the email address above. Support email is handled through Gmail; Google’s Privacy Policy applies to its processing of email.
